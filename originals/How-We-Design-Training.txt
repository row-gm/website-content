<div style="background:#FFFFFF;border:1px solid #DAD3C2;border-radius:12px;padding:24px 26px;">
<h2 style="font-family:'Arial Black', Arial, Helvetica, sans-serif;text-transform:uppercase;letter-spacing:0.02em;color:#0A2E3F;margin:0 0 8px;font-size:24px;">What we believe</h2>

<p style="font-family:Arial, Helvetica, sans-serif;font-size:14px;color:#4B5B60;line-height:1.65;margin:0 0 14px;">Eight principles. Everything in the four layers below follows from these.</p>

<div style="border:1px solid #DAD3C2;border-radius:10px;overflow:hidden;background:#FFFFFF;box-shadow:0 6px 20px rgba(10,46,63,0.10);">
<div style="display:flex;gap:16px;padding:15px 20px;background:#FFFFFF;border-top:1px solid #DAD3C2;"><span style="flex:none;font-family:'Courier New', Courier, monospace;font-weight:700;font-size:13px;width:28px;height:28px;border-radius:50%;background:#136B77;color:#FFFFFF;display:flex;align-items:center;justify-content:center;">1</span>

<div>
<div style="font-family:'Arial Black', Arial, Helvetica, sans-serif;text-transform:uppercase;font-size:13px;letter-spacing:0.02em;color:#0A2E3F;margin:2px 0 5px;">Aerobic development comes first</div>

<div style="font-family:Arial, Helvetica, sans-serif;font-size:13.8px;color:#152225;line-height:1.55;">At every age, in every group. The aerobic base is what everything else is built on, and it is the one quality that cannot be rushed later. Fast swimming built on a thin base does not hold up.</div>
</div>
</div>

<div style="display:flex;gap:16px;padding:15px 20px;background:#FAF8F2;border-top:1px solid #DAD3C2;"><span style="flex:none;font-family:'Courier New', Courier, monospace;font-weight:700;font-size:13px;width:28px;height:28px;border-radius:50%;background:#136B77;color:#FFFFFF;display:flex;align-items:center;justify-content:center;">2</span>

<div>
<div style="font-family:'Arial Black', Arial, Helvetica, sans-serif;text-transform:uppercase;font-size:13px;letter-spacing:0.02em;color:#0A2E3F;margin:2px 0 5px;">Adaptation comes from the unload, not the load</div>

<div style="font-family:Arial, Helvetica, sans-serif;font-size:13.8px;color:#152225;line-height:1.55;">Swimmers do not improve during hard training. They improve while recovering from it. Easy weeks are not time off from the plan. They are the part of the plan that pays.</div>
</div>
</div>

<div style="display:flex;gap:16px;padding:15px 20px;background:#FFFFFF;border-top:1px solid #DAD3C2;"><span style="flex:none;font-family:'Courier New', Courier, monospace;font-weight:700;font-size:13px;width:28px;height:28px;border-radius:50%;background:#136B77;color:#FFFFFF;display:flex;align-items:center;justify-content:center;">3</span>

<div>
<div style="font-family:'Arial Black', Arial, Helvetica, sans-serif;text-transform:uppercase;font-size:13px;letter-spacing:0.02em;color:#0A2E3F;margin:2px 0 5px;">Skill is developed under fatigue</div>

<div style="font-family:Arial, Helvetica, sans-serif;font-size:13.8px;color:#152225;line-height:1.55;">Perfect technique when fresh is a starting point, not the goal. Races are swum tired, so skill work belongs inside hard sets and not only in the warm-up.</div>
</div>
</div>

<div style="display:flex;gap:16px;padding:15px 20px;background:#FAF8F2;border-top:1px solid #DAD3C2;"><span style="flex:none;font-family:'Courier New', Courier, monospace;font-weight:700;font-size:13px;width:28px;height:28px;border-radius:50%;background:#136B77;color:#FFFFFF;display:flex;align-items:center;justify-content:center;">4</span>

<div>
<div style="font-family:'Arial Black', Arial, Helvetica, sans-serif;text-transform:uppercase;font-size:13px;letter-spacing:0.02em;color:#0A2E3F;margin:2px 0 5px;">Speed is maintained, never rebuilt</div>

<div style="font-family:Arial, Helvetica, sans-serif;font-size:13.8px;color:#152225;line-height:1.55;">Short, fast work appears in every phase and every group, all year. Speed is lost quickly and costs very little to keep.</div>
</div>
</div>

<div style="display:flex;gap:16px;padding:15px 20px;background:#FFFFFF;border-top:1px solid #DAD3C2;"><span style="flex:none;font-family:'Courier New', Courier, monospace;font-weight:700;font-size:13px;width:28px;height:28px;border-radius:50%;background:#136B77;color:#FFFFFF;display:flex;align-items:center;justify-content:center;">5</span>

<div>
<div style="font-family:'Arial Black', Arial, Helvetica, sans-serif;text-transform:uppercase;font-size:13px;letter-spacing:0.02em;color:#0A2E3F;margin:2px 0 5px;">We prescribe effort, not pace</div>

<div style="font-family:Arial, Helvetica, sans-serif;font-size:13.8px;color:#152225;line-height:1.55;">A zone tells a swimmer how hard to work. It does not tell them what time to hold. That is what lets one set serve a whole lane of different abilities. It also means the rest is usually the thing to fix, not the send-off.</div>
</div>
</div>

<div style="display:flex;gap:16px;padding:15px 20px;background:#FAF8F2;border-top:1px solid #DAD3C2;"><span style="flex:none;font-family:'Courier New', Courier, monospace;font-weight:700;font-size:13px;width:28px;height:28px;border-radius:50%;background:#136B77;color:#FFFFFF;display:flex;align-items:center;justify-content:center;">6</span>

<div>
<div style="font-family:'Arial Black', Arial, Helvetica, sans-serif;text-transform:uppercase;font-size:13px;letter-spacing:0.02em;color:#0A2E3F;margin:2px 0 5px;">Every season adds a layer to the foundation</div>

<div style="font-family:Arial, Helvetica, sans-serif;font-size:13.8px;color:#152225;line-height:1.55;">Each year is trained fully and raced hard, and each year is built on the one before it. The aim is a swimmer whose full potential is there to be used when physical and psychological maturity arrive. That takes patience in the early years and it pays back for the rest of a career.</div>
</div>
</div>

<div style="display:flex;gap:16px;padding:15px 20px;background:#FFFFFF;border-top:1px solid #DAD3C2;"><span style="flex:none;font-family:'Courier New', Courier, monospace;font-weight:700;font-size:13px;width:28px;height:28px;border-radius:50%;background:#136B77;color:#FFFFFF;display:flex;align-items:center;justify-content:center;">7</span>

<div>
<div style="font-family:'Arial Black', Arial, Helvetica, sans-serif;text-transform:uppercase;font-size:13px;letter-spacing:0.02em;color:#0A2E3F;margin:2px 0 5px;">We are working ourselves out of a job</div>

<div style="font-family:Arial, Helvetica, sans-serif;font-size:13.8px;color:#152225;line-height:1.55;">Our goal is to graduate athletes who are experts in their own performance. Every year a swimmer should need us a little less. A swimmer who only performs when a coach is watching has not finished developing.</div>
</div>
</div>

<div style="display:flex;gap:16px;padding:15px 20px;background:#FAF8F2;border-top:1px solid #DAD3C2;"><span style="flex:none;font-family:'Courier New', Courier, monospace;font-weight:700;font-size:13px;width:28px;height:28px;border-radius:50%;background:#136B77;color:#FFFFFF;display:flex;align-items:center;justify-content:center;">8</span>

<div>
<div style="font-family:'Arial Black', Arial, Helvetica, sans-serif;text-transform:uppercase;font-size:13px;letter-spacing:0.02em;color:#0A2E3F;margin:2px 0 5px;">A shared language, not a recipe book</div>

<div style="font-family:Arial, Helvetica, sans-serif;font-size:13.8px;color:#152225;line-height:1.55;">The plan is written down so it can be handed over, questioned, and improved. What is shared across ROW is the language and the philosophy. The creativity each coach brings to their own group is the point of the work, not a departure from it.</div>
</div>
</div>
</div>

<div style="border-left:4px solid #3FBFB0;background:#EFFAF8;border-radius:0 10px 10px 0;padding:16px 20px;margin:20px 0 0;font-size:14.5px;color:#152225;font-family:Arial, Helvetica, sans-serif;line-height:1.6;"><strong>These principles describe how we train. The ROW Way describes what we are developing.</strong> Four dimensions, twelve markers written in the swimmer&#39;s own words, and a four-step scale from &quot;learning it&quot; to &quot;when it&#39;s hard&quot;. It is open to every member, and it is what swimmer reviews and group move conversations are built on.</div>

<div style="font-family:'Courier New', Courier, monospace;font-size:9.5px;letter-spacing:0.06em;text-transform:uppercase;color:#136B77;font-weight:700;margin:0 0 2px;">Used for</div>

<div style="border-left:4px solid #3FBFB0;background:#EFFAF8;border-radius:0 10px 10px 0;padding:16px 20px;margin:20px 0 0;font-size:14.5px;color:#152225;font-family:Arial, Helvetica, sans-serif;line-height:1.6;"><strong>A zone is an effort, not a time.</strong> That holds across ages, and it holds just as strongly inside a single group. A 12&amp;U swimmer and a national swimmer can both swim a Red set in the same block. So can a 50 freestyler and an 800 freestyler, in the same lane, on the same clock.<br />
