ROW Swim Club · Family Partnership Program

Running the FPP tool

You look after the Family Partnership Program. This page tells you how, in the order you will need it. The weekly routine is at the top. Everything below explains what the words mean, and is there for the day something does not look right.

How it is put together

Two doors in, one place everything lands.

Families owe a number of volunteer points each season. How many depends on their swimmer's group. The tool works out what each family owes, collects what they have done, checks it, and adds it up.

Activity comes in through three sources, and nothing else. All three sit outside the workbook, and the tool reads them:

SourceWho fills it inWho it is about
Family Self Reporting forma familythemselves
Meet FPP sheetthe meet teamofficials at a meet
Admin Reported Data sheetyou, or a coordinatorother people

Every row from every source goes through the same gate. It needs an address that matches a family, an activity that is on the price list and still switched on, a date inside the season, and it must not be something already held. Pass and it is admitted. Fail and it is held with the reason written beside it. A row is never dropped in silence.

What happens after that depends on who made the claim. A family reporting on itself is a claim, and a claim about yourself needs somebody else to agree, so it lands as Pending and waits for you. A meet or admin row is the club's own record of what somebody else did, so it lands Counted.

The roster and last season's figures come in by a different door. They are reference, not claims, so nobody approves them — they are replaced wholesale and the tool names any row it had to drop.

Every week

One pull and one look. Ten minutes at most.

  1. 1 FPP › Pull Family Reported Data

    Brings in what families have sent, checks every entry, fetches any decisions your reviewers have made, sends out anything newly pending, and rebuilds the totals. It takes about a minute and a half. Wait for it.

  2. 2 Open the Activity Log and read anything in red

    Red means Needs fixing. The reason is written in the Checked column beside it. Put the cause right, then pull again — it will be looked at afresh and cleared by itself.

  3. 3 FPP › Approve All Pending Activity

    Family entries do not count towards a total until you do this. Meet and admin rows have already counted, because you recorded them.

If you only remember one thing

Pull, fix what is red, approve. You cannot break anything by pulling twice — anything already held is recognised and left alone, and every pull works out the totals when it finishes.

The other jobs

These come up now and then, not weekly.

After a meet

FPP › Pull Meet Reported Data. One step. It reads the meet team's sheet, brings in everything not already held, fills the Meet Check tab with anything that needs sorting out — with the row number on their own sheet, so you can point them straight at it — and works out the totals.

Every row that is not already on the Activity Log comes in, including the ones with something wrong. That is deliberate: it is what makes the list shrink instead of repeating. A row nobody can ever fix — a visiting official, a family who has left — is set to Declined once, and never raised again.

If the meet sheet is still showing last season, the pull says so in one sentence and brings in nothing at all. It will not fill your log with a season of out-of-date rows.

Activity you are recording yourself

Board roles, officials clinics, casino, bingo, fundraising — things a family should not be sending in on the form. Type them on the Admin Reported Data sheet, then FPP › Pull Admin Reported Data.

One row per person. Leave Date, Activity and Points blank below the first row and they carry down, so a night with twenty volunteers is one date, one activity, then twenty names — each with its own Details, which is what officials clinics need.

Good rows come in and the rest stay where they are, with the reason beside them. One bad address does not hold up the other nineteen. What came in is cleared away, so the sheet empties itself down to just the problems.

When the roster changes

Paste the new export onto the Roster Import tab, then FPP › Set Up › Import Roster. It rebuilds the totals by itself.

Changing what is on the form

One list, one place to edit it.

Edit the Activities tab, never the form. The tab holds the name, the type and the price together. FPP › Set Up › Update Activity Lists then writes that list out — the Family rows onto the form, the Admin rows as the drop-down on the admin sheet.

To retire an activity, set its Active column to No and run Update Activity Lists. It comes off the form and keeps its history.

Why this direction, and not the other

It used to run the other way: the tool read the form and copied anything new onto the Activities tab. Tidying the wording on the form therefore looked like three brand new activities, and they arrived with no price at all while their old rows kept the points. Nothing can flow from the form back into the tab any more.

The five words on the Activity Log

The Status column is the whole story. Everything else follows from it.

StatusWhat it meansWhat you do
New Just arrived. Not looked at yet. Nothing. The next pull picks it up.
Needs fixing Something is wrong. The reason is in the Checked column. Put the cause right, then pull again.
Pending Passed every check. A family entry, waiting for a person to say yes. Approve All Pending Activity.
Counted In the family's total. Nothing. Done.
Declined Turned down, or never fixable. Nothing. It is closed for good and will not be raised again.
Why Declined matters

Setting a row to Declined is how you stop something coming back. The Activity Log is the tool's memory. Once a row is on it, no pull will ever raise that same entry again.

What the red messages mean

These are the exact words you will see in the Checked column, and what to do about each.

“someone@example.com” does not match any family. Add it to Extra Emails, or correct it here.
Somebody used an address the club does not have on file. Put it on the Extra Emails tab, pointing at their real account address. You do this once per address, ever — after that the tool knows it.
No email address.
The entry has nobody attached to it. Type the family's address into the Submitted Email column.
“Timer” is not on the Activities tab.
Somebody reported something the club has not priced. Add it to the Activities tab and give it a value, or correct the spelling on the log.
“Timer” is switched off this season.
The activity exists but its Active column says No. Switch it back on, or decline the entry.
“Casino” is worth a different amount every time, so it needs a number.
The activity is priced as Variable. Type what this one is worth into the Points Override column.
That date is outside the season.
The date falls before Season Starts or after Season Ends on the Settings tab. Either the date is wrong, or it really was last season and should be declined.
That date is text, not a date.
The cell looks like a date but the sheet is treating it as words. Format that column as a date and retype it. Meet rows need a real date; a family may answer in words.
No date. Put the day, or say when it was in words.
Blank. A plain description works fine here — “the fall session” is accepted. Only a real date is checked against the season.
This looks like the same entry twice.
The same family, activity and date is already on the log. If it genuinely happened twice, change the Details so the two are not identical.

The Settings tab

Three columns. Only the middle one is yours.

  • Column B, the yellow Value column, is safe to change. That is what the tab is for. Nothing you run will overwrite it.
  • Column A, the names on the left, should be left alone. The tool finds each setting by its exact name. A renamed one reads as zero rather than raising an error.
  • Column C explains each one and is rewritten every time the workbook is set up, so there is no point editing it.

You can add your own rows anywhere. They will survive, but the tool will not read them — an extra row is a note to yourself unless the tool is changed to read it.

The three that matter most

First Year %, First Year Least and Activity Cap % are called out by Update Totals if they ever go blank. The others are not, so a blank Carry Forward % simply means nobody gets credit, and nothing says so.

The ones that point at another file

Paste the whole web address into any of these. You do not have to dig the long code out of the middle of it.

  • Form Link — the family form, so Update Activity Lists can write to it.
  • Review Workbook ID — where your reviewers approve entries.
  • Meet Source ID and Meet Source Tab — the meet team's file, and which tab holds who did what.
  • Meet Jobs Tab — the tab that lists their jobs, so their prices can be checked against ours.
  • Last Season Workbook and Last Season Tab — where last season's figures are read from.
  • Admin Sheet and Admin Sheet Tab — the admin reporting sheet. Leave the tab blank and the first tab is used. Leave the sheet blank and admin rows are typed on the Batch Add Activity tab instead.

When something looks wrong

A family's total is zero and should not be

Check their entries are Counted, not still Pending. If they are Counted, run FPP › Update Totals.

A whole column has gone blank

Somebody deleted a row. See the rule at the end of this guide. Running FPP › Set Up › Set Up Workbook puts the formulas back.

The menu is missing, or still shows the old items

Reload the page. The FPP menu is built when the workbook opens, so it only changes when you open it afresh.

Nothing came in from a meet

Read what the pull told you. The most common cause by far is that the meet team's tab is still pointed at last season — in which case the pull says so and brings in nothing.

An activity on the form has no value

Its Type on the Activities tab is Variable, which means the amount is typed in each time. If it is really worth the same every time, set Type to Flat and put the number in the Points column.

A script runs for a long time

That is normal. A pull takes about a minute and a half, and Set Up Workbook about seventy seconds. Let it finish rather than clicking again.

The one rule that matters

Never delete rows

Not on Activity Log, Roster, Standings or Last Season.

Every calculated column on those tabs is a single formula sitting in row 2, filling the whole column below it. Delete row 2 and that formula is gone. The column does not show an error — it just quietly stops working, and totals start coming out at zero.

To clear something, select the cells and clear the contents. Leave the rows where they are.
